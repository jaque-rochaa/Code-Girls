# Criando sua Primeira Instância Amazon EC2
**Resumo Teórico**

**Conceitos principais abordados**

**EC2 (Elastic Compute Cloud):**
- Máquinas virtuais na nuvem com capacidade de computação escalável
- Modelo IaaS com responsabilidade compartilhada entre AWS e cliente

**Componentes Essenciais:**
- AMI (Amazon Machine Image): Imagem pré-configurada do SO
- Security Groups: Firewall virtual para controlar tráfego
- Key Pairs: Credenciais SSH para acesso remoto
- EBS (Elastic Block Store): Armazenamento de bloco anexado

**Otimização de Recursos:**
- Escalabilidade vertical e horizontal
- Modelos de preço: On-Demand, Reserved, SPOT
- Gerenciamento de custos através de shutdowns inteligentes

# Ferramentas utilizadas
- Amazon EC2 (AWS)
- MobaXterm → conexão via SSH (Linux)
- Área de Trabalho Remota (RDP) → conexão via Windows
